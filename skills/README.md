# Skills

Cada skill é uma pasta com um `SKILL.md` (nome, descrição, quando usar, instruções) e, opcionalmente, scripts e recursos.
Use `_template/` como ponto de partida.

| Skill | Descrição | Cursor |
|---|---|---|
| [linkedin-post](linkedin-post/) | Posts LinkedIn bilingues (PT-BR+EN) + imagem EN sem layout fixo | `.cursor/skills/linkedin-post/` |
