# Image styles (clarity first, then rotate)

All **on-image copy must be English**. Captions/posts stay bilingual outside the art.

**Order of decisions:** (1) What must be obvious in 3 seconds? → (2) Which spatial metaphor? → (3) Which style fits? → (4) Avoid looking like the previous post.

| ID | Style | Use when the idea is… | Intuitive cue |
|---|---|---|---|
| `isometric-flow` | Soft isometric blocks on light grid | A path / latency / round-trip | Follow the arrows; timing pills |
| `three-column` | Side-by-side comparison | A→B→C progression or 3 options | Same structure per column; scan left→right |
| `dark-dual-loop` | Dark canvas, two opposing loops | Build vs break / dual feedback | Left loop vs right loop → center |
| `layer-blueprint` | Vertical stack bottom→top | Platform stack | Bottom foundations → top UX |
| `timeline-evolution` | Stages in order | Maturity / migration waves | Stage 1 → N; cost/capability rises |
| `split-metaphor` | Two contrasting halves | Duality / tension (guides↔sensors) | Left vs right; one bridge |
| `card-mosaic` | 4–6 equal cards | Checklist / principles | Equal weight; skim cards |
| `single-hero-diagram` | One centered system map | Architecture snapshot | One map; sparse labels |

## Clarity bar (fail = regenerate)

- Title states the thesis; groups are visually clustered.
- Flow direction is unambiguous (arrows / order / layers).
- ≤ ~8 short labels preferred; never wallpaper text.
- Contrast high enough for phone screens.
- Removing the caption still leaves a readable idea.

## Production method

- **Default:** handcrafted `artboard.html` / SVG → screenshot (human layout decisions).
- **Exception:** generative image only if user asks — never as the first choice for diagrams.

## Anti-patterns

- Pretty but meaningless decoration (gradients with no structure)
- Style chosen only “to be different” while hiding the idea
- Same palette + same layout as the previous post *without* clarity gain
- Tiny unreadable English text
- Crowding > ~12 text labels on one frame
- Purple-on-white default cliché unless the content demands it
- **AI-template look:** perfect centering, identical pill rows, fake handwriting fonts, glossy numbered orbs, stock sticky-note clipart, Midjourney infographic chrome
