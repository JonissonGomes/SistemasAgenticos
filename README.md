## Como usar

1. Novo projeto: copie `projetos/_template/` para `projetos/<nome-do-projeto>/`.
2. Nova skill: copie `skills/_template/` para `skills/<nome-da-skill>/`.
3. Todo problema inesperado vira um arquivo em `corner-cases/` (modelo no README da pasta).
4. Atualize os índices acima ao adicionar algo.

## Convenções

- Pastas e arquivos em `kebab-case`.
- Documentos em Markdown.
- Cada pasta tem um `README.md` explicando seu propósito.
